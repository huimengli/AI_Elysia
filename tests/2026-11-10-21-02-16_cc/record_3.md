# 轮 3 — 抗干扰后训练（SNR 混合 + 真人样本加权，v0.5）（2026-11-10 21:38–21:52）

- 场景（用户追加需求：「将一些噪音和已有的音频样本做混合,然后进行抗干扰的后训练」）：既有噪声池 `openWakeWord/background/noise`（24 个 16 kHz 单声道文件）与真人正/负样本、v0.3 合成正/负样本按 **SNR -5 / 0 / 5 / 10 dB** 混合（seed 42，共 164 条带噪 clip，编号延续 11xx）；另加 8 条「纯噪声窗口」（按真人正样本电平定标，不含语音）作 FP 抵抗负样本；真人 clip 行重复 ×5、带噪 clip ×2 后与 v0.4 特征合并成 v0.5，`steps 2500`、`max_negative_weight 1` 训练出 `aili_xiya_v0.5.onnx`
- 期望（写死在 record 追加节）：带噪真人 recall 上升、带噪负样本 fp 不升；若 fp 升则回退 v0.4
- 实际（阈值 0.7）：v0.5 = 合成 rec 0.60 / fp 0.00、真人 rec 0.00 / fp 0.00、带噪真人 rec 0.00 / 带噪 fp 0.00；阈值 0.5 时真人 rec 0.50 / fp 0.40，阈值 0.4 时真人 rec 1.00 / fp 0.90（分数区间 0.478±0.02 与噪声 0.495± 重叠）
- 结果：**FAIL**。带噪 fp 确实降到 0.00（需求方向达成），但 recall 全面塌陷，且带噪真人 mean 0.465 < 干净真人 mean 0.478 —— 真人正样本在噪声下没有守住
- 备注：根因是真人正样本太少（2 训练 clip）且录音呼唤本身弱（ASR 只在 4 处认出、24 s 出现幻觉），SNR -5 dB 的「正样本」几乎不可辨；`max_negative_weight 1` 下负样本占绝对多数，模型学到「压低一切」。要真正抗干扰，需要 ≥20 条干净真人呼唤（安静+带噪各半）作正样本 —— 已写入 need_user.md Q8 请求补录
