## 4. 方法学结论（可复用，写进规矩）

1. **打分必须逐件新建实例**（HB-032 播种独立性）：跨件连续复用 4 个 Model 实例会把上一件 mel 缓冲带进下一件、检出后 `reset()` 清零缓冲 → 正样本峰值从 0.873 压到 0.483（三实例完全相同，独立性丢失）。一次性 560 次构造会 `onnxruntime bad allocation`；正确做法是**逐件新建 + `del` + `gc.collect()`**，并在打分前停掉 `:9880`（Free 15.9 GB）。
2. **行重复比只移动灵敏度曲线**（既有结论）：本批正 ×5 / 合格负 ×1 依旧没有产生近音判别力。
3. **多音色是召回轴，不是判别轴**：音色多样性让 7 个音色的 3 条正文本全部检出（21/21），部署召回合计 +1；但近音词在**任何音色**下峰值 ≥0.70（Kokoro 负样本 0/17 合格），与真唤醒同量级 → 不能作负样本。
4. 依赖打通（本机 pip 卡死，走 tuna wheel/sdist 直装）：`soundfile 0.14.0`、`ordered_set 4.1.0`、`pypinyin 0.55.0`、`cn2an`、`proces`、`jieba 0.42.1`（无 wheel，走 sdist）→ Kokoro `lang_code="z"` 通路可用；可复用安装器 `.tmp/wheel_install.py`。
