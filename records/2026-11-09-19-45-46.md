# 2026-11-09-19-45-46 一键启动：matplotlib 权限警告 + 三服务全掉线

- 提出时间：2026-11-09 19:45:46
- 提出人：用户（双击 `start_all.bat` 后粘贴窗口输出）

## 用户现象

1. 双击 `start_all.bat`，GPT-SoVITS 窗口打印：
   `mkdir -p failed for path C:\Users\楼听\AppData\Local\matplotlib: [WinError 5] 拒绝访问。`
   → Matplotlib 退到临时缓存目录 `GPT-SoVITS-main\matplotlib-o1codm3e`，并提示建议设置 `MPLCONFIGDIR`。
2. 之后 GPT-SoVITS 正常加载 Elysia 权重、`Uvicorn running on http://127.0.0.1:9880`，浏览器访问 `GET /` 与 `GET /favicon.ico` 均 404（正常：TTS 只暴露 `/tts`）。
3. 我实测（`.tmp\bats\chk2.log`，19:46）：`:8080` / `:9880` / `:7860` **均无 LISTENING**，`tasklist` 无 `llama-server` / `python.exe`；只剩浏览器探测 `:9880` 留下的 `TIME_WAIT`。即三个服务此刻全部不在运行。

## 分析

- matplotlib 的 `WinError 5` 是**警告不是致命错误**：Matplotlib 需要写字体缓存目录，默认路径 `AppData\Local\matplotlib` 被拒绝访问（该机对该目录写入受限），于是自动退回临时目录，TTS 仍可用；代价是每次启动多一次字体缓存重建、启动变慢。
- `start_all.bat` 设计上只启动 GPT-SoVITS + Jarvis，**不启动 llama.cpp**（脚本注释写明「start it yourself」），且没有设置 `MPLCONFIGDIR`，所以每次双击都会出现上述警告；`cmd /k` 窗口被关掉时对应 python 进程一起消失，服务随之掉线（本次 3 端口全空）。

## 方案（本次实施）

1. 在 `start_all.bat` 里设置 `MPLCONFIGDIR=%~dp0.tmp\mplconfig` 并预建目录，消除 `WinError 5` 警告并让字体缓存可复用。
2. 补 llama.cpp `:8080` 启动段（与 `.tmp\start_services.ps1` 同款参数），并加 `:8080` 端口占用检查 → 双击一次起齐三服务。
3. 用「Win+R → Alt+R 放行安全警告」通道启动，再实测三端口监听 + `GET /api/health` 三灯在线。
