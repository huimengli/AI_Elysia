# 2026-11-09-20-35-43 状态灯新增「唤醒」（排在语音识别左侧）

- 提出时间：2026-11-09 20:35:43
- 提出人：用户原话：「语音识别左边再加一个 '唤醒'」

## 需求

顶部状态显示器右侧的服务灯由 3 盏变 4 盏，顺序：**唤醒 / 语音识别 / LLM / TTS**。唤醒灯反映 openWakeWord（`aili_xiya_v0.3.onnx`，threshold 0.65）是否在线、是否在监听、最近一次得分与触发时间。

## 现状

- `GET /api/health`（`jarvis/web.py` `_health_snapshot()`）只返回 `asr / llm / tts` 三项；`asr.warm` = faster-whisper 模型是否已加载。
- `jarvis/wake.py` 的 `listen_for_wake_word()` 在独立线程里循环，模型 `oww` 与 `_peak`、`_last_detect` 都是函数内局部变量，**外部读不到**，所以健康接口无法报告唤醒状态。
- `jarvis/static/index.html` 的 `pollHealth()` 每 5 s 拉一次，只更新 `lamp-asr / lamp-llm / lamp-tts` 三盏灯。

## 方案

1. `jarvis/wake.py`：新增模块级 `state` 字典（`online/model/threshold/listening/peak/last_detect`），在模型加载成功后置 `online=True`，每次 `predict` 更新 `peak` 与 `listening`（`_mic_pause` 期间为 `False`），触发时更新 `last_detect`。
2. `jarvis/web.py`：`_health_snapshot()` 读取 `jarvis.wake.state`，返回 `wake` 项（放在 `asr` 之前），`/api/health` 由三灯变四灯。
3. `jarvis/static/index.html`：在 `lamp-asr` 左侧插入 `唤醒` 灯（`lamp-wake`），`pollHealth()` 按 `wake.online` 上色，标题显示 `模型 / threshold / 最近得分 / 最近触发时间`。
4. 重启 Jarvis（`:7860`）使改动生效，实测 `GET /api/health` 含 `wake`、`GET /` 的 HTML 含第 4 盏灯与 JS 绑定；验证 3 轮写入 `tests/2026-11-09-20-35-43_cc/` 并累积 `tests/opinion.md`（全程文本通路，零截图）。
