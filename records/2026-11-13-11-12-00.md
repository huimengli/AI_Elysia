## 实现方案

1. **新模块 `jarvis/tools/browser.py`**：
   - `connect()`：优先 `connect_over_cdp("http://127.0.0.1:9222")`（你的浏览器）；不可用时按配置回退到 `launch(channel="msedge", headless=True)`（验收/无授权时自启，不抢你的前台窗口）；连接与 page 句柄缓存在模块内，断线自动重连。
   - `read_screen_browser()`：用 `page.evaluate` 抽取**叶子元素文本 + `getBoundingClientRect()` 中心点**，输出与 OCR 路径同格式 `text | x,y`（viewport CSS 像素），限制最多 200 行；无文字返回 `NO_TEXT`。
   - `find_on_browser(text)`：`page.get_by_text(text, exact=False)` → `bounding_box()` → 返回**页面坐标**并提示用 `click_on_page`；找不到时 `page.mouse.wheel(0, 600)` 下滚一次再找（不碰系统滚动）。
   - 新工具 `click_on_page(x, y)`：`page.mouse.click(x, y)`。`click_at`（pyautogui 屏幕坐标）保持不变，两者坐标域不同，返回文案里明确写清用哪个。
2. **`jarvis/tools/desktop.py` 的 `read_screen` / `find_on_screen`**：**优先浏览器路径**，浏览器不可用（无授权/无页面）才回退到原 OCR，回退行为不变（不破坏现有能力）。
3. **`jarvis/tools/router.py`**：注册 `click_on_page`（中文名「点击页面坐标」），并在 `read_screen` / `find_on_screen` 的 description 里写明「优先浏览器快照，零截图」。
