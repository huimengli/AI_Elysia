# 2026-11-10-17-31-10 ASR 不能转写的真因（HF 缓存缺环境变量）+ 启动预热

- 提出时间：2026-11-10 17:31:10
- 提出人：用户追问：「你说的这个问题是 asr 有问题?」——针对上一批登记的遗留：真实语音轮 STT 两次 `ConnectError WinError 10054`、`asr.warm=false`、VAD 录满 30 s

## 诊断（读日志 + 读代码，不猜）

- `.tmp\jarvis3.log:17-22` 原文：`[STT] cuda failed to load (Got: ConnectError: [WinError 10054] ... An error happened while trying to locate the files on the Hub, and we cannot find the appropriate snapshot folder for the specified revision on the local disk. Please check your internet connection and try again.), falling back to CPU` → 之后 `[STT] None transcription failed`、`[STT] CPU transcription also failed`。
- 对照 `jarvis/stt.py`：`_get_model()` 在构造 `WhisperModel(stt["model"], device, compute_type)` 时若失败才不改 `_model_device`；日志打出 `_model_device = None` 说明**异常发生在模型加载阶段**，不是推理阶段 → 「连接被重置」是 faster-whisper 去 **Hugging Face Hub 找模型快照** 时的网络失败（国内到 huggingface.co 连接被重置），不是麦克风/解码/显卡问题。
- 模型在磁盘上**是存在的**：`C:\Users\楼听\Desktop\git\JarvisAi\.hf-cache\hub\models--Systran--faster-whisper-small\snapshots\536b066...`（实测 `model.bin` 存在）。而默认用户缓存 `%USERPROFILE%\.cache\huggingface\hub` 里只有 bert/MeloTTS 等，**没有 whisper-small**。
- 根因：`start_all.bat` 的 Jarvis 窗口会设 `HF_ENDPOINT=https://hf-mirror.com` + `HF_HOME=%~dp0.hf-cache` + `HF_HUB_DISABLE_XET=1`；我 16:46:57 用 `pwsh` 通道重启 Jarvis 时**没有带这三个环境变量**，于是 `HF_HOME` 指向默认缓存 → 找不到快照 → 联网 → `ConnectError 10054`。`asr.warm=false` 是同一现象的下游（模型压根没加载成功）。
- 结论：**不是 ASR 代码缺陷，是重启通道丢了环境变量**（我的操作失误），加上「whisper 只在首次转写时懒加载」让问题只在真人语音时才暴露。
- 顺带实测：`config.yaml` 写 `device: cuda`，但这台机器 CUDA 驱动版本不够（`CUDA failed with error CUDA driver version is insufficient for CUDA runtime version`），`_get_model()` 自动回退 CPU（`[STT] Loaded small on cpu`）——这是既有且正确的行为。VAD 在安静环境下正常（`Speech detected (rms=0.0222)` → `Silence detected, stopping recording`，7.5 s 音频成功转写）。

## 方案

1. 重启 Jarvis 必须带 `HF_ENDPOINT/HF_HOME/HF_HUB_DISABLE_XET`（写进 progress 执行通道，避免再犯）。
2. `jarvis/main.py` 新增 `_warm_stt()`：启动时在后台线程调 `_get_model()` 预加载 whisper，使 `asr.warm` 立刻为 `true`、首次转写不再承担加载成本，加载失败也能在启动日志里立刻暴露（而不是等真人说完话才发现）。
3. 3 轮验证（零截图）：① health `asr.warm=true` + 启动日志的加载行；② 真人语音轮成功转写（`[You] ...`）；③ WS 链路复测（工具事件带中文 `label`）。
