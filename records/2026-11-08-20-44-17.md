## 修复节（12:35 追加，20 轮第 9/10 轮暴露的 3 条工具层缺陷）

20 轮跑到第 9、10 轮（`tests/2026-11-08-20-44-17_cc/record_9.md`、`record_10.md`）暴露三条，**根因都在工具层，不是模型**：

1. **HB-033 音量虚假成功**：`set_volume` 不检查 returncode/输出，无条件返回「音量已设为 X%」；加上 `[MMDeviceEnumerator] -as [IMMDeviceEnumerator]` 在 PowerShell 里返回 null（COM coclass 不被 `-as` 激活）；加上服务在 harness 后台任务里 python 子进程 `%TEMP%` 禁写，`Add-Type` 编译被拒。修法：C# 类内 `new MMDeviceEnumerator()` 做 COM 激活 + **复读音量作证据**（差 ≤2 才报成功）+ 读 `eMultimedia` 端点 + `$env:TEMP` 指到工作区 `.tmp/pscompile`。
2. **HB-034 屏幕读取 GBK 崩**：`_ocr_image` 用 `text=True`，reader 线程按 GBK 解码 OCR 输出崩在 `0x9c` → `result.stdout` 变 None → `'NoneType' object has no attribute 'strip'`。修法：PS 设 `[Console]::OutputEncoding = UTF8` + `text=False` + UTF-8 解码（照同族 `_ps_utf8`）。
3. **HB-035 天气 ascii 崩**：中文地名未 URL quote、`format=` 里带中文。修法：`quote(location, safe="")` + `format=j1`（纯 ASCII JSON，中文在 Python 侧拼）。
