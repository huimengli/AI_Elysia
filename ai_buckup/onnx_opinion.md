## 0. 测量口径（固定，新模型请逐字复用）

- **部署管线（权威口径，与线上 `jarvis/wake.py` 完全一致）**：1 s 零填充 → 1280 样本逐块送 `openWakeWord.Model.predict` → 计 score ≥ 阈值的事件 → 检出后 `reset()` → 强制 2.0 s 冷却；**单探针串行**（并发 4 个探针会在 `openwakeword/utils.py:397 _streaming_melspectrogram` 触发 `MemoryError`）。
- **离线矩阵（`predict_clip` 打分）**：合成正/负、真人留出、带噪真人（SNR -5/0/5/10 dB）、定标纯噪声（rms<15），阈值 0.4–0.8。
- **HB-032（必须遵守）**：`AudioFeatures.__init__` 用 `np.random` 播种缓冲 → 同一音频同一模型**跨实例分数漂移 ±0.02–0.07**。贴近阈值的判定必须 **≥3 个独立 Model 实例复测取多数**；训练日志的 `Final Model False Positives per Hour: 0.0` **只统计 400 条合成 val_fp，不可采信**。
- **写死判据（2026-11-11 起）**：13 次真人呼唤检出 ≥10、真人近音 fp ≤1、合成对抗 ≤4、定标纯噪声 0、现场环境音 ≤1。

## 5. 结论（跨 9 版，勿再重复踩）

1. **行重复比只移动灵敏度曲线，不产生近音判别力**：v0.7（近音负 ×5）检出 10→5；v0.8（正 ×5 / 负 ×3）检出 12 但近音 fp 升；v0.9（真人新负 ×2）检出 14，近音 fp 也升到 9–11。同一件在 v0.9 的峰值比 v0.6 更高（爱莉雅 0.838 vs 0.782，希雅老师 0.804 vs 0.788，米雅希 0.745 vs 0.735）→ **负样本行数 = 灵敏度旋钮，不是判别力来源**。
2. **TTS 合成负样本对本项目无效（实测排除）**：GPT-SoVITS 的参考音频就是爱莉希雅本人音色，同音色合成近音词在 v0.6 峰值 0.796–0.839，**高于真人唤醒词整件的 0.73–0.75** → 入库等于造一个「比真唤醒词更像唤醒词」的负样本，训练它就是教模型拒绝唤醒词（v0.4 真人 rec 0.50 / v0.5 塌陷的同机制）。16 件里 7 件 ≥0.7 剔除、9 件低分件（0.575–0.694）也排除。**真人录音是唯一有效负样本来源**。
3. **禁 爱丽西亚 / 艾丽西亚 / 爱X西亚 类**（与「爱莉希雅」几乎无区别），也不得进 `custom_negative_phrases`；允许的真人近音负样本是 爱丽安娜 / 爱丽丝 / 米希雅 / 爱莉雅 / 米雅希 / 希雅 / 希雅老师。
4. **真人件入库条件是「不含唤醒词 + 文件名即真值」，不按峰值剔除**；峰值只作验收证据。两峰之间的间隙**不能当负样本**（`noise_tr_1200` 最高 0.822 > 多数真呼唤窗口）。
5. **严格判据在三个阈值下都无法同时满足**：「真人近音 fp ≤1」与「13 次 ≥10」互斥。按 Q12「更好就换」采用 **v0.9 + 阈值 0.75**（12 检出 / 近音 6 / 无关 2 / 对抗 4 / 长噪 1 / 环境 0），两轴同时优于 `v0.6 + 0.7`（10 / 6–7 / 4–5 / 4 / 1 / 0–1）；`v0.9 + 0.80` 是「近音 fp ≤1」最接近的档位（6 / 2 / 2 / 2 / 0 / 0），代价是 13 次只检出 6。**「近音 fp ≤1」记为未达标。**
6. **未达标的直接原因是真人负样本量**（近音仅 7 件，需 ≥10；无关短句 7 件，需 ≥10；干净呼唤补 ≥10 次、带噪补 ≥8 条、竞品唤醒词真人句 ≥5 条、安静 10 s 环境音）→ 逐条列在 `need_audio.md` 第 5 节，路径留空 = 需用户录。
7. `aili_xiya_v0.7/.8/.9.onnx`（各 13,735 B）与 `train_config_v07–v09.yaml` 在 `openWakeWord/`（被 `.gitignore` 排除）；只有 `aili_xiya_v0.3.onnx` 入 Git（用户批准，AGENTS §4 禁 push）。
